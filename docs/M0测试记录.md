## 0. 开发板确认

对照 `C:\Users\Administrator\Downloads\ESP32-S3-N16R8_User_Guide.pdf`（YD-ESP32-S3 / MICRO ROBOTICS）：

- **COM** Type-C = CH343P USB-UART（COM4），本项目烧录/串口就用它；**USB** Type-C = 原生 GPIO19/20。
- **GPIO13/14 在 P1 的 19/20 脚引出**，当前 `RECORD=13`、`MIC BCLK=14` 不需要改线；两者是 ADC2，只做数字 I/O。
- GPIO35/36/37 用于模组内部 Flash/PSRAM，排针有但不可用；GPIO48 是 WS2812 RGB LED（需桥接）；GPIO0=BOOT，45/46=strapping，43/44=UART0。
- 当前 7–12（EPD）、1/4/5/6/13（按键）、14/15/16（MIC）、17/18/21/47（AMP）、39/40（I2C）、2（电池 ADC）全部落在 P1/P2 排针上。

完整排针表见 [`board_pinmap.md`](board_pinmap.md)。

## 3. E0：band 位置/高度实测

测试帧为 `bench` 底图 + 带内 `BAND n`（4 倍字）；每次先重画整帧内存，再调用 `epd_band_update()`。

| y0 | h | 平均耗时 | 结果 |
| --- | --- | --- | --- |
| 35 | 70 | **346 ms** | ok |
| 95 | 70 | **346 ms** | ok（当前主带） |
| 170 | 40 | **298 ms** | ok（结果 band 候选） |
| 170 | 70 | **346 ms** | ok |
| 230 | 40 | **298 ms** | ok |
| 整屏 `epd_partial_show_full` | 300 | **709 ms** | ok |
| 清洁周期 | 3× | **709 / 709 / 710 ms** + LUT reload | ok |

**结论**：

- `y=35/95/170/230` 都能稳定带状刷新，带状外不动；**结果 band 可以放在 y=170**。
- **40 行带约 298 ms**，比 70 行 346 ms 少约 48 ms；如果 M1 的单词卡能压进 40–50 行，优先用更窄的带。
- 70 行带 + 整屏 + 清洁的数值与之前 346/700/2.1 s 一致，没有回归。

> 视觉上需要人工确认“带状外是否完全不动、带内是否只有文字变化”；串口只能证明 BUSY 时间和返回 ok。E0 的照片/目视记录建议在 M1 布局定稿时补。

## 5. 5 键驱动

`buttons_init()` 成功，5 个引脚均配置为上拉输入：

```text
PREV=GPIO4  NEXT=GPIO5  PLAY=GPIO6  RECORD=GPIO13  SYNC=GPIO1
```

驱动特性：

- 20 ms 消抖；
- 短按在释放时触发；
- 800 ms 长按在按住期间触发；
- 事件队列 16 条，支持多键；
- 全部为 RTC GPIO，后续可做 EXT1 深睡唤醒。

`bench keys 2` 的起始掩码实测为 **0x00**，说明 5 个键都没有被误判为常按；`buttons_init()` 也没有报错。

**待确认**：物理按键是否已接好。运行 `bench keys 5`，依次按 5 个键，应看到 `PREV/NEXT/PLAY/RECORD/SYNC short`；长按 1 s 应看到 `long`。当前串口测试未包含人工按键动作。
