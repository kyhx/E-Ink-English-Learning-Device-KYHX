**显示子系统已经稳定：70 行带状局刷约 346 ms；M0 分区/LittleFS/5 键/bench 已通过；M2 录音、WAV、VAD、20 条连续录音已通过；上电清屏 2.14 s；设备采集固件和 PC 同步已跑通。**

## 1. 硬件

| 项 | 参数 |
| --- | --- |
| 目标 MCU | **ESP32-S3-WROOM-1-N16R8**，16 MB Flash / 8 MB Octal PSRAM |
| 当前台架 | YD-ESP32-S3 开发板（仅用于验证，不是最终 BOM） |
| 屏幕 | **SSD1619A + HINA-E042A13-A0 + 成品驱动板**，4.2" 400×300 |
| 串口 | 当前 COM4（CH343P）；目标 **CH343K**（ESSOP10，自动下载待核对） |
| 按键 | PREV=4，NEXT=5，PLAY=6，RECORD=13，SYNC=1；全部 RTC |
| EPD | BUSY=7，RST=8，DC=9，CS=10，MOSI=11，SCK=12 |
| 目标音频 | **LMD2718 + NS4168 成品模块**（麦克风+功放）；接口/供电待 pinout |
| 台架音频 | 旧：MS4030 + MAX98357A（仅历史） |
| 目标喇叭 | **8 Ω / 1 W**；NS4168 需 5 V 才能输出 1 W |
| 电池/电流 | 目标 1S 2500mAh / BQ24074 / INA219；BAT_ADC=2，I²C 39/40 |

完整排针/strapping 注意事项：[`board_pinmap.md`](board_pinmap.md)。

## 2. 构建与烧录

```powershell
$env:IDF_PATH='F:\esp\v6.1\esp-idf'
. 'F:\esp\v6.1\esp-idf\export.ps1'
idf.py build
idf.py -p COM4 flash
```

| 模式 | 开启方式 | 用途 |
| --- | --- | --- |
| 默认 M2 | `CONFIG_APP_MODE_DEMO=n`、`CONFIG_APP_MODE_COLLECT=n` | 录音/回放页 + bench |
| 旧 50 词 demo | `CONFIG_APP_MODE_DEMO=y` | 显示回归 |
| 采集模式 | `CONFIG_APP_MODE_COLLECT=y` | 5 键采集页 |

采集固件单独构建：

```powershell
pwsh -File tools\collect\build_collect_firmware.ps1
# -> artifacts/firmware/E-Ink-collect.bin
```

当前默认固件 app 约 **388 KB**（`0x5ed50`），3 MB factory 剩余 88%。

## 5. 当前问题

### 5.1 设备端评分未闭环

- 缺 `main/ai/` TFLM 封装与 C 端 mel；
- 缺结果页（分数/通过/耗时/免责声明）；
- 当前模型是 mel-only，不知道目标词；最终要词条件化；
- 最低 200 条、目标 600 条设备自采数据；不能直接用公开句级模型当最终模型。

### 5.2 音频模块待定型

- 目标：**LMD2718 + NS4168 成品模块 + 8Ω 1W 喇叭**；
- NS4168 需 **5V** 才能输出 1W（8Ω 1W 约 2.83Vrms，3.3V 不够）；
- 模块的 I2S/模拟接口、SD/GAIN、供电范围必须拿到厂商 pinout；
- 当前固件仍是旧台架 `MS4030 + MAX98357A`，不能直接套用；
- 旧实测见 [`M2测试记录.md`](M2测试记录.md)，只作历史。

### 5.3 其他

- 5 键物理按下/长按尚未人工确认；
- 自采数据仍是工具/试点，尚未达到最低 200 条；
- `data/reference/oxford` 版权音频仅本地，不提交；
- partial LUT 是 AGPL 来源，发布前必须处理（见 `THIRD_PARTY_NOTICES.md`）。

## 7. 常见坑

| 现象 | 原因/处理 |
| --- | --- |
| 条纹/残影 | 每 20–30 次带状刷新做清洁；上电已自动清屏 |
| 局刷只动 Y 不动 X | SSD1619A 无 source X 窗口，只能带状真局刷 |
| 屏不亮/全黑 | 检查 BUSY=7 高忙、RST=8、3.3 V、CS=10 |
| 录音全 0/很小 | 麦克风 3.3 V、L/R=GND、BCLK/WS/SD；先 `bench audio rec 2000` |
| 录音开头爆音 | 固件已丢弃前 100 ms；不要改回 0 |
| 播放无声/很小 | SD=47 高、5 V、喇叭差分、GAIN 15 dB、`bench audio gain` |
| OpenPronounce 评分 500 | 权重缺失/路径错；看 [`openpronounce.md`](openpronounce.md) |
| `huggingface.co` 超时 | 用 ModelScope 同名仓库；当前权重已放 `artifacts/openpronounce/hf` |
| 找不到模型/数据 | 新结构在 `artifacts/`；见 [`artifacts.md`](artifacts.md) |
| 编译路径报错 | `build/` 只放 IDF；`build-collect/` 已删除，可脚本重建 |
