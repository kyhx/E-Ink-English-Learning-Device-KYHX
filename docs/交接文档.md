## 0. 一句话现状

**HINK-E042A13-A0（4.2" 单色 SSD1619A）已经能用 70 字节 partial LUT 做 400×300 全帧、739 ms/词的“无可见闪”快速刷新；50 个单词居中、每词停留 1 秒、每 25 词清洁一次，跑完显示 DONE 并深睡。它不是窗口级真局刷，仍全帧扫描/写入。**

## 2. 软件环境与构建

- ESP-IDF **v6.1**
- 构建/烧录端口：**COM4**
- 工程是标准 ESP-IDF 工程，不是 Arduino

  - Octal PSRAM
  - CPU **240 MHz**
  - `CONFIG_PM_ENABLE` **未开启**
  - `CONFIG_FREERTOS_HZ=1000`
  - tickless idle **未开启**

### 2.3 当前固件行为

烧录后自动运行，无测试宏：

1. `epd_init()` 建立 SPI/GPIO，正常面板初始化
2. `epd_partial_init(epd_lut_partial_70)` 硬件复位 + EPaperDrive 初始化 + 加载 partial LUT
3. 开机清洁：全白 → 全黑 → 底图（3 × 709 ms）
4. 50 个单词：每词 739 ms 刷新 + 1 s 停留
5. 第 25 词、第 50 词后各清洁一次
6. 显示 DONE，`epd_deep_sleep()`

## 4. 当前刷新方案（最重要）

### 4.1 初始化序列

`epd_partial_init()` 做：

```text
硬件复位
0x74 0x54
0x7E 0x3B
0x01 0x2B 0x01 0x00
0x0C 0x8B 0x9C 0xD6 0x0F
0x3A 0x21
0x3B 0x06
0x3C 0x03
0x11 0x03
0x2C 0x00
0x37 0x00 0x00 0x00 0x00 0x80
0x21 0x40
0x22 0xC7
0x21 0x00
0x32 + 70 字节 partial LUT
```

### 4.2 单次刷新

`epd_partial_update()` 当前做：

```text
0x22 0x80 + 0x20       重新开时钟
0x22 0xC7              设置刷新序列
0x11 0x03              数据方向
0x44 0x00 0x31         X 窗口 0..399
0x45 0x00 0x00 0x2B 0x01 Y 窗口 0..299
0x4E 0x00
0x4F 0x00 0x00
0x24 + 15000 字节       写整帧
0x20                    触发
等待 BUSY
0x24 + 15000 字节       再写一次基线
```

### 4.3 清洁周期

`clean_cycle()`：

```text
全白  -> 0x24 + 0x20，约 709 ms
全黑  -> 0x24 + 0x20，约 709 ms
底图  -> 0x24 + 0x20，约 709 ms
重载 partial LUT
```

当前在 **START / 第 25 词 / 第 50 词** 各做一次。  
建议产品中改成 **每 20–30 次局刷**或残影明显时再做，不要每次开机都做。

### 4.4 实测时间

| 项目 | 时间 |
| --- | --- |
| 单次全帧刷新 | **739 ms**（偶尔 740 ms） |
| 单词停留 | 1 s |
| 每词节奏 | **约 1.74 s** |
| 清洁一次 | 3 × 709 ms ≈ 2.1 s |
| 50 词总时长 | 约 87 s + 清洁，约 93 s |

### 4.5 为什么“不闪”

这套 LUT 是 transition-only：

```text
LUT0 BB = 0x00   黑->黑，不驱动
LUT1 BW = 0x82   黑->白，驱动
LUT2 WB = 0x50   白->黑，驱动
LUT3 WW = 0x00   白->白，不驱动
LUT4 VCOM = 0x00
```

- 写整帧 400×300 时，每个像素的 old/new 状态都完整；
- 未变化像素走 WW/BB，不驱动；
- 只有文字笔画走 BW/WB，被短脉冲翻转；
- 所以视觉上**没有整屏闪**，只有文字在变。

窗口缩小到 128×70 时，窗口外像素没有新的 old/new 数据，控制器仍扫描整屏 gate，会出现“框外闪”。  
**这是波形/数据完整性限制，不是窗口大小问题。**

### 4.6 关键结论

- 当前不是“窗口级真局刷”，而是 **全帧 transition-only 快速刷新**；
- 视觉上无可见闪，739 ms/词；
- 面板仍然扫描整屏，数据也是整帧 15000 字节；
- 相对 OTP 全刷 4–6 s，刷新时间大幅缩短，像素驱动也减少；
- 因此可以写“**局部刷新降低刷新能耗**”（像素级局部驱动），但不要写“窗口外不扫描/微功耗局刷”。

## 5. 已做过的实验与结论

| 方案 | 时间 | 结果 |
| --- | --- | --- |
| OTP 全刷 `0xC7` | 4–6 s | 稳定，全屏闪 |
| 原 OTP + 区域写 RAM | 4–6 s | 只省 SPI，面板仍全刷 |
| SSD1683 227B fast LUT（强行） | 1936 ms | 全屏闪，不是 partial；GPL，已移除 |
| GaAs Full LUT | 2085 ms | 清晰全刷；代码已清理移除 |
| GaAs GS LUT | 450 ms | 很淡/残影；已移除 |
| EPaperDrive 128×70 窗口 | 684 ms | 单词正确，框外整屏闪 |
| **400×300 全帧 transition-only（当前）** | **739 ms** | **无可见闪，单词正常** |
| 连续 30 次（小窗口） | 680 ms/次 | 轻微残影，清洁可恢复 |
| 清洁周期 | 3×709 ms | 完全恢复干净 |

详细记录见 `docs/局刷测试记录.md`，其中 2.8 节解释了“为什么全帧反而不闪”。

## 6. 已知问题 / 风险

### 6.1 许可证（高优先级）

- 当前 `epd_lut_partial.h` 的 70 字节 LUT 和初始化/刷新序列来自 **HalfSweetStudio/EPaperDrive**，该库是 **AGPL-3.0**。
- 本工程 README 原写的是 MIT；**两者不兼容**。
- 如果要发布/商用/开源，必须三选一：
  1. 整个项目按 AGPL-3.0 开源；
  2. 联系作者取得授权；
  3. 从 datasheet 独立重写 partial LUT/序列。
- 仅本地论文实验可暂时使用，但要在论文/文档中注明来源与许可证。

### 6.2 不是窗口级真局刷

- 仍是 400×300 全帧扫描/写入；
- 小窗口会出现框外闪；
- 不要对外宣称“只刷新局部窗口”。

### 6.3 功耗未实测

- 当前 CPU 240 MHz、PM 关闭、tickless 关闭；
- 每词后 `vTaskDelay(1000)` 是 **240 MHz 空转 1 秒**；
- 开机清洁固定 2.1 s；
- 没有电流/能量实测数据；
- 不能直接宣称“低功耗局刷”，只能宣称“相对 OTP 全刷降低刷新时间/像素驱动”。

### 6.4 残影/寿命

- 连续局刷会累积轻微残影；
- 当前每 25 词清洁一次；
- 长期（1000+ 次）、温度变化、面板批次差异未验证；
- 建议每 20–30 次清洁，并做 100–500 次循环测试。

### 6.5 代码遗留

- `epd_epd_dis_part()` 是可选实验接口，当前未使用；
- 可保留用于对照，也可在最终版删除；
- `epd_display_area()` 仍是 OTP 全刷路径，不是局刷。

## 8. 下一步建议

### 8.1 如果要继续做产品

1. 处理 AGPL 许可证；
2. 把 demo 改成“按键翻词 + 按需刷新”；
3. 加 light sleep / CPU 降频 / 关 Wi-Fi；
4. 测功耗和残影；
5. 接真实词库、Leitner 复习、音频/AI。

### 8.2 如果论文要求“真局刷”

当前屏 + 当前 LUT 做不到窗口外完全不动。三条路：

1. 换 2.9" SSD1680 / 标准 4.2" partial 屏；
2. 向面板厂要真正的 partial 波形 LUT；
3. 修改指标为“全帧 transition-only 快速刷新 + 相对节能”，并补实测。

### 8.3 如果只要当前效果

- 保持 400×300 全帧；
- 每 20–30 词清洁一次；
- 按需刷新；
- 深睡前 `epd_deep_sleep()`；
- 不要把 1 秒停留做成连续空转。

### 9.2 常见问题

| 现象 | 原因/处理 |
| --- | --- |
| 全白/无显示 | 检查 CS 是否整段拉低、0x21 是否只发 1 字节、0xB1/时钟 |
| BUSY 超时 | 检查 0x22 序列、F7 是否挂死、电源 |
| 单词倒置 | Y 递减时必须反向取行 |
| 框外闪 | 小窗口数据不完整；当前用全帧规避 |
| 残影 | 做清洁周期；不要连续几百次不清洁 |
| 刷新后写 RAM 无效 | 0xC7 后时钟关闭，需要 0x22=0x80 + 0x20 |
| 颜色发红/三色 | 本屏是单色；不要按三色初始化 |
