# 公开语音/发音数据调研

> 结论：**没有和本课题完全同构的公开数据集**（单词级、设备麦克风、中文学习者、正确/错误二分类）。
> 但有几套数据可以分别解决“预训练、错误标签、参考发音、鲁棒性”问题；自采 200–600 条仍是论文主数据。

## 1. 最相关

### speechocean762（首选预训练/评分）

- 内容：**5000 句**非母语英语，说话人母语为普通话，儿童/成人各半；5 位专家独立打分。
- 标注：句级 accuracy/fluency/completeness/prosodic；**词级 accuracy/stress**；**音素级 0/1/2 分**；还提供 `mispronunciations`（哪个音被读成什么）。
- 许可：**CC BY 4.0**（可商用，需署名）。
- 规模：下载约 **520 MB**。
- 适合：预训练、评分回归、阈值化二分类、错误类型分析。
- 局限：是**句子朗读**，不是单词卡；要做词级二分类需要词边界（MFA 对齐）和阈值（如 word accuracy ≥8 为正、≤6 为负，7 分剔除）。
- 链接：<https://www.openslr.org/101/>、<https://github.com/jimbozhang/speechocean762>

### L2-ARCTIC（首选错误标签/说话人独立）

- 内容：**24 位**非母语英语说话人（印地/韩/中/西/阿/越），约 **27.5 小时**、**27,042 条**朗读；每人约 1 小时。
- 标注：每人 **150 条**人工标注（100 条所有人共用 + 50 条按母语难点选），标出**替换、删除、加音**三类错误，含词/音素边界。
- 许可：**CC BY-NC 4.0**（非商业；需在官网填表申请下载）。
- 适合：把“有任一音素错误”聚合为词级“错误”，训练二分类；做按说话人独立验证；分析错误类型。
- 局限：非商业许可；朗读句子，不是单词卡；需要解析 TextGrid 并聚合到词。
- 链接：<https://psi.engr.tamu.edu/l2-arctic-corpus/>

## 3. 推荐组合

**方案 A（最省时间，适合论文）**

1. `speechocean762` 做**预训练/评分回归**：词级 accuracy 阈值化，得到“正/负”辅助标签。
2. `L2-ARCTIC` 做**错误标签/说话人独立**：把替换/删除/加音聚合为词级错误。
3. 自采 600 条做**最终训练/测试**；公开数据只进训练/验证，不进你的测试集。
4. 参考发音用 `VCTK`/`LJSpeech`，或自己录 100 个词（更贴合设备麦克风）。

**方案 B（只做最小闭环）**

1. 先不碰大数据集；用 `speechocean762` 的 100–200 条词级片段跑通 `log-Mel → 小 CNN → int8`。
2. 再自采 200 条做二分类；公开数据只做“流程验证”。

**方案 C（不推荐）**

只用公开句子数据训练，直接拿到设备上测单词。域不匹配（朗读句子 vs 单词卡、录音设备不同、错误定义不同），准确率会明显掉。

## 4. 怎么把公开数据变成“正确/错误”标签

### speechocean762

- 词级 `accuracy` 0–10：
  - 正样本：≥ 8
  - 负样本：≤ 6
  - 7 分：边界，先剔除或单独做阈值敏感性
- 也可用 `mispronunciations` 非空作为“错误”的强标签。
- 需要词边界：用 Montreal Forced Aligner（MFA）对齐，或使用数据集自带词级时间戳（若版本提供）。

### L2-ARCTIC

- TextGrid 里有词层、音素层、错误标签：
  - 一个词内出现 substitution/deletion/addition → 负样本
  - 无错误 → 正样本
- 只取人工标注的 150 条/人，避免用未标注数据当负样本。
- 注意：`err` 旧标签在 v4 之后被细分为更具体的错误类型。

## 6. 下载顺序建议

1. `speechocean762`（520 MB）——先跑通词级/音素级解析。
2. `L2-ARCTIC`（申请后下载）——解析 TextGrid，做错误标签。
3. `VCTK` 或 `LJSpeech`——参考发音；若只要 100 个词，直接自录更省事。
4. `Speech Commands` / `LibriSpeech dev-clean`——只在需要预训练前端时再下。
5. `Common Voice`——最后考虑，体积大且无细粒度标签。

## 7. 已实测

2026-10 用 `speechocean762` 跑了 2000 条平衡子集（官方 125/125 说话人划分）：

- val accuracy **69.7%**，F1 **69.4%**，AUC **0.759**
- int8 TFLite：与 PyTorch 标签一致率 **98.3%**，准确率 70.0%
- 模型 6,066 参数，int8 11.5 KB

这不是单词卡准确率（句级评分 + 2 秒中心裁剪 + mel-only），只验证公开数据管线和 int8 部署。完整记录见 [`public_test_speechocean762.md`](public_test_speechocean762.md)。

## 8. 关键提醒

- 公开数据不能替代课题要求的“自采 ≥200 条”；验收/答辩会看采集与标注过程。
- 公开数据和自采数据的**录音设备、信噪比、说话风格**不同；训练时要做增益/噪声/重采样增强，测试必须用自采说话人独立集。
- 不要把公开数据混进最终测试集；否则“换人/换设备”结论不成立。
- 论文里建议报告三组结果：**public-only**、**own-only**、**public 预训练 + own 微调**，这比只报一个准确率更有说服力。
