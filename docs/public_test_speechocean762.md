# 公开数据测试：speechocean762

## 数据

- 语料：[speechocean762](https://www.openslr.org/101/)，CC BY 4.0
- 内容：5000 句非母语英语，母语均为普通话，儿童/成人各半，5 位专家独立打分
- 划分：官方 `train` / `test` 各 125 人，**说话人零重叠**
- 本次使用：每类每 split 随机 500 条，共 **2000 条**（train 1000 / test 1000，正负各 500）
- 标签：句级 `accuracy >= 8` → 1，`<= 7` → 0
- 特征：现有 2 秒 log-Mel 前端，句音频中心裁剪/补零到 2 秒
- 模型：TinyMelNet，6,066 参数，mel-only（无条件化）
- 训练：20 epochs，batch 32，AdamW，特征增强，early stopping

> 这不是单词级发音对错任务。它用真实的非母语语音和人工评分，验证“数据→特征→训练→int8→部署”管线；不能把 69.7% 当成最终单词卡准确率。

## 结果

| 指标 | 值 |
| --- | --- |
| accuracy | **0.6970** |
| precision | 0.7014 |
| recall | 0.6860 |
| F1 | 0.6936 |
| ROC-AUC | 0.7594 |
| 混淆矩阵 | `[[354, 146], [157, 343]]` |
| 类别 0（需改进）召回 | 354/500 = 0.708 |
| 类别 1（良好）召回 | 343/500 = 0.686 |
| 平衡多数基线 | 0.500 |

平衡子集上多数类基线是 50%，模型 **69.7%**，约高 19.7 个百分点；AUC 0.759 说明排序能力有限但明显非随机。

## 错误分析

在 1000 条验证集上按年龄/时长切片：

| 切片 | n | accuracy |
| --- | --- | --- |
| 儿童 | 480 | **0.613** |
| 成人 | 520 | **0.775** |
| 时长 1.5–2.5 s | 66 | 0.712 |
| 时长 2.5–3.5 s | 377 | 0.679 |
| 时长 3.5–4.5 s | 262 | **0.611** |
| 时长 4.5–6.0 s | 175 | 0.737 |
| 时长 ≥6.0 s | 120 | 0.875 |

- **儿童语音明显更难**：61.3% vs 成人 77.5%。公开集一半是儿童，设备目标更可能是成人学习者，这个差距要单独报告。
- 句子时长与 `p(correct)` 相关系数约 **-0.576**：句子越长，中心裁剪丢的内容越多，模型越倾向判“错误”。这说明 2 秒裁剪是公开数据测试的主要混杂因素，不是模型真实发音判断。
- 因此下一步应优先做**词级切分**（L2-ARCTIC 的 150 条/人）或**全句时间归一化**，而不是继续加 CNN 层。

## 部署一致性

| 路径 | 与 PyTorch 标签一致率 | 准确率 | 最大 logit 差 | 最大概率差 |
| --- | --- | --- | --- | --- |
| ONNX | 1.000 | 0.697 | 6.6e-07 | — |
| float TFLite | 1.000 | 0.697 | 6.1e-07 | 3.0e-07 |
| int8 TFLite | **0.983** | **0.700** | 0.378 | 0.118 |

- int8 模型 **11.5 KB**，比 float 26.9 KB 小；标签一致率 98.3%，准确率没有掉。
- ONNX / float TFLite 与 PyTorch 基本逐位一致。
- int8 的 logits 会偏移，但 softmax 概率和标签基本保持；论文里应报告**概率差/标签一致率**，不要只报 logits。

## 解释与局限

1. **任务不一致**：公开语料是句子级评分，设备是 2 秒单词卡；模型只能看到句子的中心 2 秒，会丢失开头/结尾。
2. **标签阈值**：`accuracy >=8` 为正、`<=7` 为负是人为阈值；换阈值结果会变。7 分是“有少量错误”，归到负类偏严格。
3. **数据量**：2000 条平衡子集只用于管线验证；全量 5000 条、或 L2-ARCTIC 的 150 条/人错误标注，是下一步。
4. **说话人独立**：已使用官方 125/125 说话人划分，不是随机按样本切分。
5. **域偏移**：录音设备、朗读风格、句子长度都与设备不同；69.7% 不能直接外推到真实单词卡。

## 下一步

- **L2-ARCTIC**：词/音素级替换、删除、加音标注，更接近“单词对错”；CC BY-NC 4.0，需申请。
- **全句时间归一化**：把整句压到 2 秒，而不是中心裁剪，看公开数据上限。
- **词条件化 / 参考 Mel**：当前 mel-only 基线不知道“应读哪个词”，这是设备任务的关键下一步。
- **自采 600 条**：最终论文主数据；公开数据只做预训练/对照。
