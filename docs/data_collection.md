# 数据采集与标注

目标：采一套**自己的**单词跟读数据，至少 200 条，建议 600 条；每条 2 秒、16 kHz、单声道，带说话人/单词/正确性/错误类型。

> 公开数据（speechocean762、L2-ARCTIC）只能做预训练/对照；论文验收要求的是**自采数据**。采集前先征得参与者同意，只记录匿名说话人编号，不记录姓名。

## 1. 词表

`data/words.csv`：

```csv
word_id,word,meaning,ipa
0,apple,苹果,
1,book,书,
```

- 50 个词与固件 `main/word_view.c` 的演示词表一致。
- `ipa` 先留空；后续可用 CMUdict/词典补，不影响采集。
- 要换词表，保持 `word_id` 唯一即可；GUI 会重新读取。

## 2. 采集协议

### 环境

- 安静房间，关风扇/空调直吹。
- 麦克风距离嘴 **10–20 cm**，不要正对气流。
- 先试录 2 条，检查峰值在 0.05–0.9；太小人声不够，太大会削顶。

### 每条样本

1. 选说话人编号（`S01`、`S02`…，不要用真名）。
2. 选单词。
3. 点“录音 2 秒”，自然读一遍；不要刻意拖长或喊。
4. 试听；看 Mel 是否有清晰能量。
5. 标“正确/错误”；错误类型可选：替换、吞音、加音、重音、其他。
6. 点“保存样本/标注”。

**不要**把读错的样本重录到“正确”为止；读错也是负样本，保留并标注。每个词建议录 **2 次**，保留自然差异。

### 600 条设计（建议）

| 项 | 设计 |
| --- | --- |
| 说话人 | 6 人（3 强 / 3 弱，男女混合，最好含非母语者） |
| 单词 | 50 个/人 |
| 每词条数 | 2 次 |
| 合计 | 6 × 50 × 2 = **600** |
| 训练/测试 | 4 人训练 / 2 人测试（按说话人切，不按样本切） |
| 目标类别 | 正确约 70%、错误约 30%；自然错误，不伪造 |

如果 6 个人全是“读得很准”，负样本会太少。解决办法是**招募不同水平的人**、加入少量更难词/更快语速，而不是把正确样本硬标成错误。

## 3. GUI 操作

```powershell
.\.venv-train\Scripts\python.exe tools\pipeline\gui.py
```

或双击 `tools/pipeline/GUI.bat`，打开 **采集 / 标注**：

- 顶部：说话人、单词、麦克风；麦克风可刷新。
- 中间：录音 2 秒、试听、停止、导入 WAV、保存、删除。
- 左侧：Mel 预览、标签、错误类型、备注。
- 右侧：已采集列表；选中一条可改标签后“保存样本/标注”。

### 标注已有样本

1. 右侧选中一条；
2. 试听；
3. 改“正确/错误”、错误类型、备注；
4. 点“保存样本/标注”。

### 导入设备/手机 WAV

点“导入 WAV”一次导入一条，自动重采样到 16 kHz、裁剪/补零到 2 秒；试听后标注保存。批量导入暂未做，设备端录音落地后可再加。

## 4. 目录与格式

```text
data/collected/v1.0/
├── labels.csv
└── audio/
    ├── S01_00_<timestamp>.wav
    └── ...
```

`labels.csv`：

```csv
utt_id,file,speaker_id,word_id,label,error_type,notes,split
S01_00_1792958639,audio/S01_00_1792958639.wav,S01,0,1,,, 
```

- `label`：1=正确/可接受，0=错误
- `error_type`：可选，只用于分析，不喂模型
- `split`：留空即可；训练时按 `speaker_id` 自动留出说话人。若要固定官方划分，可填 `train`/`test`
- `utt_id` 必须唯一；GUI 用 `说话人_词号_时间戳` 生成

## 5. 采集后检查

```powershell
.\.venv-train\Scripts\python.exe tools\pipeline\check_collected.py `
  --data-dir data\collected\v1.0
```

会检查：

- WAV 是否存在、可读、16 kHz、单声道、约 2 秒；
- 是否有静音/削顶/重复音频；
- 每个说话人的正确/错误数量；
- 标签是否只有 0/1。

有 `ERRORS` 先修；`WARNINGS` 至少逐条试听确认。

## 6. 训练

```powershell
.\.venv-train\Scripts\python.exe tools\pipeline\run.py `
  --data-dir data\collected\v1.0 `
  --out build\pipeline_own_v1 `
  --epochs 40 --batch-size 16 --augment
```

不写 `--val-speakers` 时，脚本会按说话人留出约 25%。600 条建议先做 4/2 说话人划分；论文里再补 LOSO。

## 7. 标注口径

- **正确**：音素基本准确，重音/节奏可接受；允许轻微口音。
- **错误**：明显替换、吞音、加音、重音错误，或听成另一个词。
- 边界样本（7 分左右）先标“错误”并写备注；后续可做阈值敏感性分析。
- 同一个人的同一词多次录音，分别标注；不要因为“上次读对了”就默认这次正确。

## 8. 已知限制

- PC 麦克风与设备 **MS4030（INMP441 兼容）** 的频响/底噪不同；设备端 I2S 录音尚未接入，最终要补设备端录音。
- GUI 一次只导入一条；600 条主要靠现场录。
- 当前是单词级二分类；音素级错误定位需要强制对齐，后续再做。
- 采集与标注是论文的一部分：保留原始 WAV、`labels.csv`、采集日期/设备/环境说明。
